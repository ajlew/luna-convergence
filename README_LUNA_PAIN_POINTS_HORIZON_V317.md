# Luna v3.17 — Pain Points + Strategic Horizon

This update is additive on top of Luna v3.16 and preserves the complete v3.15/v3.16 feature set.

## What changed

- Monthly reports state the human problem before the astrology.
- Every major problem includes the consequence of leaving it alone and one active response.
- Strategic Horizon now states explicitly that month-end is not the finish line when the responsible condition remains active.
- The next slow-planet station is shown as the next material change; longer sign exits remain visible as background shifts even when they fall next month or next year.
- Jupiter, Saturn, Uranus, Neptune and Pluto remain the long-cycle layer and appear only when the existing monthly evidence gives them enough weight.
- Web Monthly, Markdown and both customer PDF pathways now render the same problem/horizon layer.
- Evidence-path date windows use the true minimum start and maximum end, preventing reversed ranges such as 29-24 September.
- Monthly QA now rejects backwards narrative windows and adjacent repeated customer words.
- Existing Solar Clock, Solar Gate, trajectory, decision truth-gate, relief windows, Forecast Inventory, payment/order flow, Daily, Monthly, Yearly, print and technical evidence remain intact.

## Public language

Internal strategy remains game-theoretic, but customer copy avoids game/player/equilibrium jargon. Luna says the problem, the consequence, the time available and the move.
