# Luna v3.24 — Behavioural Natal Signatures

This release keeps the existing Free Natal Snapshot structure and adds a compact interpretation layer beneath the three core patterns.

## What changed

- Adds **Your strongest signatures** to the free natal result.
- Ranks aspects by **human interpretive value**, not orb/technical strength alone.
- Personal combinations such as Moon–Saturn, Sun–Moon, Moon–Mercury, Sun–Saturn and Sun–Mercury outrank tight generational contacts such as Uranus–Pluto.
- Adds short behaviour-first labels such as **Emotionally reserved**, followed by original Luna interpretation, **Strength**, **Watch**, and an optional question.
- Keeps the existing chart wheel, three repeating patterns, chart evidence, privacy rules, birth-time uncertainty rules, Daily, Monthly, Solar Year, Stripe and fulfilment flows intact.

## Design rule

`trait → lived behaviour → strength → watch → evidence`

The source astrology remains visible through the aspect/orb evidence line, while unsupported biographical claims are deliberately avoided.
