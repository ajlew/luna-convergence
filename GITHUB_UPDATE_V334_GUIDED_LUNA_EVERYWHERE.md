# Luna Convergence v3.34 — Guided Luna Everywhere

## What is now LLM-led

| Customer surface | Input to Luna LLM | Delivery |
|---|---|---|
| Home + Daily Horoscope | Calculated aspect, houses, phase, orb, convergence and sky events | Generated once per fact packet, then cached |
| Weekly View | Seven calculated days, ranked events and deduplicated major sky events | Generated by GitHub Action, validated and committed |
| Monthly | Calculated dated events, houses, planets and natal contacts | Generated once per fact packet, then cached |
| Free Natal Snapshot | De-identified positions, houses and aspects | Private generated reading, then cached by facts |
| Your Year Ahead | De-identified transit-to-natal contacts, periods, exact hits and major events | Private generated reading, then cached by facts |

The previous hard-coded prose is no longer preferred. It remains only as automatic fallback if the model configuration is missing, the provider fails or validation rejects the response.

Calculations, checkout, payments, email, report controls and routes are unchanged.

## Add the Groq settings to Streamlit

GitHub Actions secrets do not automatically appear inside Streamlit. Open:

**Streamlit Community Cloud → luna-convergence → Settings → Secrets**

Add these lines, keeping any existing secrets already there:

```toml
LUNA_VOICE_MODE = "published"
LUNA_VOICE_BASE_URL = "https://api.groq.com/openai/v1"
LUNA_VOICE_MODEL = "openai/gpt-oss-20b"
LUNA_VOICE_API_KEY = "PASTE_YOUR_GROQ_KEY_HERE"
```

Never place the real key in a GitHub file.

## Keep the GitHub settings for weekly publishing

Repository variables:

- `LUNA_VOICE_BASE_URL` = `https://api.groq.com/openai/v1`
- `LUNA_VOICE_MODEL` = `openai/gpt-oss-20b`
- `LUNA_VOICE_PROVIDER` = `groq`

Actions secret:

- `LUNA_VOICE_API_KEY`

Under **GitHub → Settings → Actions → General → Workflow permissions**, select
**Read and write permissions** if the weekly workflow cannot commit its validated JSON.

For later weeks:

1. Open **GitHub → Actions**.
2. Select **Generate and publish weekly Luna voice**.
3. Click **Run workflow**.
4. Enter any date in the Monday–Sunday week.
5. Use `Australia/Sydney` for the publication timezone.
6. Run from the branch connected to the live Streamlit app.

The workflow commits only a response that passes the fact and language validator.

## Safety and cost controls

- Visitors never trigger weekly generation.
- Runtime Daily, Monthly, Natal and Year Ahead responses are cached for 24 hours by their calculated facts.
- Personal prompts contain calculated chart geometry, not name, email, raw birth date, raw birth time or birthplace.
- Invented planets, numeric evidence, guaranteed outcomes, mismatched fact hashes and malformed prose are rejected.
- Set `LUNA_VOICE_MODE = "off"` in Streamlit secrets to restore all existing deterministic prose immediately.
