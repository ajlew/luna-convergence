# Daily Reading Version 3

## Why consecutive dates previously looked the same

The earlier selector ranked aspects mainly by raw strength and closeness.
A very tight Neptune–Pluto sextile therefore became the headline trigger on
consecutive days. Because both planets move slowly, the first paragraph and
headline changed very little.

The Sun also remains in the same whole-sign house for many consecutive days,
so using the Sun house as the main daily voice added another layer of repetition.

## What now changes each day

The new selector:

- excludes slow outer-planet-only aspects from the daily headline;
- strongly prioritises Moon aspects;
- favours Mercury, Venus and Mars;
- detects the day on which an aspect is closest to exact;
- distinguishes applying from separating aspects;
- retains slow aspects in the technical background rather than using them as
  the main emotional hook.

Sagittarius now receives different leading triggers on these dates:

- July 28: Moon opposition Mercury — “Read between the lines”
- July 29: Venus square Mars — “Chemistry wants a reaction”
- July 30: Moon sextile Saturn — “Let consistency seduce you”

## Relationship-first editorial voice

Every daily reading now contains a visible **Love & desire** section. The
relationship language uses romance-story emotional architecture without making
unsupported claims about a specific event.

The archetypes are activated only when the astrology supports them:

- Saturn: slow burn, loyalty, reserve, age or status difference;
- Uranus: rebel energy, surprise, unconventional attraction;
- Pluto: magnetism, secrecy, power and emotional intensity;
- Neptune: fantasy, longing, unavailable or idealised attraction;
- Mars: pursuit, chemistry, friction and direct desire;
- Venus: attraction, pleasure, value and relational choice;
- Moon: emotional safety, instinct and the need to feel understood.

The writing deliberately separates compelling fantasy from unhealthy behaviour.
It can acknowledge mystery, danger, power or age-gap attraction while still
protecting autonomy, boundaries, mutual respect and emotional safety.

## Customer-facing formatting correction

The daily customer copy no longer inserts Markdown bold markers inside HTML
paragraphs. This removes the visible `**` symbols shown in the mobile screenshots.
Planet names and technical aspects remain formatted normally inside the expandable
evidence section.
