# Cardinal-Sign Narrative Refinement

This release corrects four remaining repetition and timing issues.

## Changes

1. The shared aspect question now changes with the sign's activated house.
2. The bridge sentence in Today's Story rotates through multiple structures.
3. Venus–Mars language no longer repeats “chemistry and direct desire.”
4. Convergence windows are labelled as current, approaching or recent.

For July 29, 2026, the selector now checks in this order:

1. a convergence currently containing the reading date;
2. the nearest convergence approaching within fourteen days;
3. the most recent convergence that ended within fourteen days.

In the current cardinal-sign test, the app displays:

```text
Approaching convergence window: August 07–August 18
```

The expired July 16–27 cluster is no longer presented as currently active.

Shared evidence such as Venus square Mars and its strength score remains
consistent because that is the genuine common sky. Customer-facing language
changes with the houses activated for Aries, Cancer, Libra and Capricorn.
