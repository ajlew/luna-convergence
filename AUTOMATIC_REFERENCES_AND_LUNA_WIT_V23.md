# Automatic References and Luna Wit v2.3

## Print behaviour

The reference area remains closed on screen. When printing, all four sections
open automatically:

- Why Luna sees this
- Solar Convergence
- Key dates and planetary timing
- Full technical evidence

The former `Include evidence` checkbox has been removed. Print CSS forces all
reference content to display, including when the browser uses Ctrl+P rather
than Luna's button. The print button also opens every disclosure, waits for web
fonts, then opens the browser print dialog.

## Shared Do / Don't voice

Daily, monthly and yearly products now call the same `luna_do_dont()` function.
The lines remain practical but add dry Luna humour.

Sagittarius August example:

- **Do:** Follow the effort. Chemistry can book its own flight.
- **Don't:** Mistake attention for value. A boarding pass is not commitment.

## Astrology Zone comparison

Luna borrows Susan Miller's strongest editorial tools: a recognisable narrator,
concrete situations and memorable phrasing. It does not copy Astrology Zone's
long continuous article format, repeated certainty or seven-page density.
Humour is concentrated in the headline and Do / Don't strip so the reading
stays sparse.
